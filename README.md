# 梁寓租务 0.1

面向少量用户的本地租务管理系统。第一版聚焦「房源 → 租客 → 合同」，租客录入时可使用本地 PaddleOCR 识别身份证人像面。

## 已实现

- 超级管理员登录、修改密码、账号管理
- 唯一只读管理员：可查看全部业务数据，不能修改、收款、抄表、导出或备份
- 租客账号自动创建，登录名为当前房号；退租自动改名归档并停用
- 独立租客中心：只读查看自己的合同、租金账单和水电记录
- 租客中心顶部有「老租客推荐新租客，成功入住领现金大红包」静态横幅
- 超级管理员完整数据导出与导入恢复
- 房屋与房间管理：空置、已租、维修中
- 租客档案：姓名、手机号、紧急联系人、身份证信息
- 身份证人像面上传、本地 OCR、字段提取、号码校验、人工确认
- 身份证号脱敏展示，证件原图需登录后访问
- 合同创建、到期提醒、办理退租；新合同默认长期有效，可手动填写到期日
- 新合同固定每月 15 日收租；入住当天收完整首月租金，首张 15 日账单为过渡期
- 租金账单：旧合同按自然月，新合同按 15 日周期自动生成
- 租金收款：交租日期、收款方式、备注、已收/未收/逾期、撤销收款
- 收租页同时显示本期租金、本期租客水电和本期合计
- 水电抄表：按月按房间记录水表、电表，自动计算用量与费用
- 水电单价设置、批量抄表、已收/未收、历史记录、CSV 导出
- 首页概览：出租率、合同提醒、房态一览、待租房间、最近租客
- SQLite 单文件数据库，合同与房间状态自动联动
- 响应式网页，电脑和手机浏览器均可使用

## 只读管理员

- 系统只允许创建一个只读管理员账号
- 可查看与超级管理员相同的房源、租客、证件、合同、租金和水电数据
- 不能新增、编辑、删除、退租、登记收款、撤销收款、抄表、修改单价
- 不能访问账号管理和数据备份，不能导出数据
- 可以自行修改自己的登录密码
- 超级管理员可在「账户与管理 → 账号管理」创建、启停和重置只读账号
- 只读账号会包含在完整备份中

## 租客账号与租客中心

- 系统角色：超级管理员、只读管理员、租客
- 租客账号默认使用当前房号作为登录名
- 默认密码为「房号 + 身份证后 4 位」；没有身份证时使用手机号后 4 位
- 租客不能自行修改密码，密码由超级管理员在账号管理中重置
- 退租后旧账号自动改名为「房号-退租日期」并停用，新房客可重新使用房号
- 租客换房时登录名同步变为新房号
- 租客中心顶部有推荐大红包横幅，下面是「本期租金、本期水电费、本期应付」三张汇总卡片
- 本期应付卡会显示「已缴清 / 待缴金额 / 本期暂无账单」状态
- 租客只能查看自己的合同、未缴及下月租金账单、最近 2 个月水电记录及收款状态
- 租客水电明细显示上期数、本期数、用量、金额、换表标记和备注
- 不能查看其他租客、其他房间、房东汇总，也不能修改任何数据
- 租客签约后自动创建账号，登录名取当前房号
- 退租后账号自动改名为「房号-退租日期」并停用
- 超级管理员可在「账户与管理 → 账号管理」重置密码、启停账号

## 登录会话

- 密码最少 4 位，不强制 8 位
- 超级管理员：7 天
- 只读管理员：30 天
- 租客：90 天
- 固定到期，不自动续期
- 修改密码会踢掉同账号其他设备的会话
- 重置、停用、重新启用账号会使旧会话失效
- 导入备份会使所有现有登录失效

## 数据备份

- 超级管理员可在「账户与管理 → 数据备份」导出 ZIP 备份
- 备份包含业务数据、租客账号、只读管理员账号和身份证照片，不包含当前超级管理员密码
- 导入会覆盖所有业务数据和租客账号，但保留当前超级管理员
- 导入前会自动生成一份当前数据备份，可在导入完成后下载
- 导入会清除租客现有登录状态，需要重新登录
- 备份文件未加密，包含敏感信息，请存放在受控位置

## 收租

新合同：

- 固定每月 15 日收租
- 入住当天收首月租金：入住日到次月同日的前一天，收完整一个月
- 首月自动登记为微信已收
- 首张 15 日账单是过渡期：
  - 首月结束日 < 15 日：首月结束次日到 14 日按天折算补差，15 日到下月 14 日收整月租金
  - 首月结束日 ≥ 15 日：首月结束次日到下月 14 日整个短周期按天折算
- 从下一张 15 日账单起，每月 15 日至下月 14 日固定收一个月租金
- 提前退租：未收账单按实际天数 ÷ 30 折算
- 已收账单不自动退款，系统计算应退差额，线下退还

旧合同：

- 仍按自然月账单和原收租日运行
- 目前 102 合同保留旧规则
- 203 合同已一次性迁移到 15 日周期

所有合同：

- 每个账单只支持登记一次全额收款，可撤销后重新录入
- 收款记录包括交租日期、收款方式、备注
- 退租时删除未来未收账单

## 水电抄表

- 先进入「水电」页面设置水费单价（元/吨）和电费单价（元/度）
- 每个在租房间每月保存一条水表和电表记录
- 每条记录自动带出该房间最近一次读数；首次抄表需要填写起始读数
- 支持单间录入和批量抄表
- 只给当月有在租租客的房间抄表，空置房不记录水电
- 每条记录可标记已收 / 未收
- 换表或清零导致本期读数小于上期时，需要勾选换表并填写备注
- 删除或修改早期读数受到后续月份记录限制，避免破坏读数链路

## 数据与隐私

- 数据库：`app-data/rental.db`（包含租金账单与水电记录）
- 身份证照片：`app-data/uploads/id-cards/`
- OCR 临时图片：`app-data/uploads/tmp/`，超过 24 小时自动清理
- 本地使用 PaddleOCR，线上使用 RapidOCR；图片不发送给第三方 OCR 服务
- 手机号、身份证号等属于敏感信息，请勿把 `app-data/` 目录上传到公开仓库

## 备份

```bash
.venv/bin/python scripts/backup.py
```

备份写入 `backups/<时间戳>/`，包含数据库副本和上传文件压缩包。建议每天备份，并定期验证能否恢复。

## 技术结构

```text
backend/
  app/
    routers/       API 接口
    services/      OCR、身份证解析、文件处理
    models.py      SQLite 数据模型
    main.py        FastAPI 应用入口
  requirements.txt
frontend/
  src/             React 页面与组件
  dist/            生产构建产物
app-data/          数据库、密钥与证件照片
scripts/backup.py  备份脚本
```

技术栈：FastAPI + SQLAlchemy + SQLite + React + Vite + PaddleOCR（本地）/ RapidOCR（线上）。

## 正式部署前

1. 修改超级管理员初始密码，或通过环境变量 `RENTAL_ADMIN_PASSWORD` 设置初始密码（仅首次建库生效）。
2. 若开放给租客使用，先在「账户与管理 → 账号管理」重置需要发放的账号密码，并把临时密码线下告知租客。
3. 使用 Nginx/Caddy 等反向代理并启用 HTTPS。
4. 设置 `RENTAL_COOKIE_SECURE=true`。
5. 限制 `app-data/` 的文件权限，仅服务账号可读。
6. 为 `scripts/backup.py` 配置每日定时任务，并定期测试完整备份导入。
7. 不要把本地 OCR 服务直接暴露到公网。

## 当前限制

- OCR 为通用 OCR + 证件版式规则，不是专用身份证识别模型；模糊、反光或严重倾斜时需手工修正。
- 首次 OCR 会加载模型，可能需要十余秒；如果模型尚未下载，需要首次联网获取，之后会快很多。
- 身份证号会做校验位和出生日期校验，但仍需人工核对原图。
- 一个租客同一时间只能有一份生效合同，一个房间同一时间也只能有一份。
